-------------------------------------
git checkout --orphan nouvelle-histoire
```Crée une nouvelle branche sans aucun historique Git, tout en conservant les fichiers présents dans le dossier.

git add -A
```Ajoute tous les fichiers au prochain commit, y compris les suppressions et modifications.

git commit -m "Initial commit"
```Crée le premier commit de la nouvelle histoire, avec le message indiqué.

git branch -D main
```Supprime l’ancienne branche `main`, avec son ancien historique. `-D` force la suppression.

git branch -m main
```Renomme la branche actuelle `nouvelle-histoire` en `main`.

git push -f origin main
```Envoie la nouvelle branche `main` vers le dépôt distant `origin`. `-f` force le remplacement de l’historique distant.
```La dernière commande est nécessaire uniquement si tu veux aussi effacer l’historique sur GitHub ou un autre dépôt distant. 
```Elle peut affecter les autres personnes qui utilisent ce dépôt.
